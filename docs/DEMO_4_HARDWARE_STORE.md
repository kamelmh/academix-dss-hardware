### Minute 0:30-1:30 — The Solution (Show the Dashboard)

**Screen**: Academix Dashboard with 40 hardware items
**Script**:
> "I built a Decision Support System using Excel and VBA. It uses the Wilson EOQ formula — the same math used by Fortune 500 companies — to calculate exactly when to order and how much."

**Show**:
- Dashboard with KPIs (total stock value, items below ROP, items below SS)

**Screen**: EOQ Calculation sheet

- Wilson EOQ formula with real numbers
