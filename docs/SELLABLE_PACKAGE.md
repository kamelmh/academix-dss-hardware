# Academix DSS — Sellable Package Guide

## Package Overview

The Academix DSS is a complete inventory management system for Algerian hardware stores (quincailleries). It's built in VBA/Excel, making it accessible to any business with Microsoft Office.

## Package Contents

### Core Files
| File | Description |
|------|-------------|
| `ERP_dss_v13.4_hardware_store.xlsm` | Main application file |
| `docs/USER_GUIDE.md` | Comprehensive user guide (FR/EN) |
| `docs/FIRST_RUN.md` | First-run setup documentation |
| `docs/README.md` | Technical documentation |

### Features Included
- **First-Run Wizard** — Automatic setup on first open
- **40 Demo Articles** — Pre-loaded for training
- **9 Algerian Suppliers** — With real tax IDs (NIF/NIS/RC)
- **Wilson EOQ** — Economic Order Quantity calculations
- **CMUP** — Weighted Average Cost (SCF compliant)
- **ABC Classification** — Automatic inventory categorization
- **Barcode Printing** — Generate barcodes for articles
- **Invoice Generation** — Create and print invoices
- **Delivery Notes** — Print delivery receipts
- **Dashboard** — Real-time KPIs and charts
- **Reports** — ABC, aging, supplier performance, stock summary
- **Backup System** — Automatic backups on open
