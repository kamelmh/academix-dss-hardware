# Academix DSS — Démarrage Rapide

## 30 Secondes

```
1. Ouvrez le fichier Excel (.xlsm)
2. Cliquez "Activer le contenu" (barre jaune)
3. L'assistant s'affiche — remplissez les infos de votre quincaillerie
4. Cliquez "Charger les données de démonstration" pour voir le système en action
5. Commencez à utiliser le tableau de bord !
```

## Les 8 Boutons Principaux

| Bouton | Fonction | Raccourci |
|--------|----------|-----------|
| **Articles** | Gérer votre catalogue | `Ctrl+Shift+A` |
| **Fournisseurs** | Gérer vos fournisseurs | `Ctrl+Shift+F` |
| **Entrée Stock** | Enregistrer une réception | `Ctrl+Shift+E` |
| **Recherche** | Trouver un article | `Ctrl+Shift+R` |
| **Facturation** | Créer une facture | `Ctrl+Shift+I` |
| **Rapports** | Voir les statistiques | `Ctrl+Shift+P` |
| **Paramètres** | Configurer le système | `Ctrl+Shift+S` |
| **Accueil** | Retour au tableau de bord | — |

## Fonctionnalités Clés

### Gestion de Stock
- **CMUP** (Coût Moyen Unitaire Pondéré) — calcul automatique
- **ABC** — classification automatique (A: 80% valeur, B: 15%, C: 5%)
- **Wilson EOQ** — quantité économique de commande
- **DSI** — jours de stock moyen

### Commandes & Réceptions
1. Cliquez **Entrée Stock**
2. Sélectionnez le fournisseur
3. Ajoutez les articles (code, quantité, prix)
4. Validez — le stock se met à jour automatiquement
5. Imprimez le bon de réception

### Facturation
1. Cliquez **Facturation**
2. Entrez les informations client
3. Ajoutez les articles vendus
4. La facture se génère automatiquement
5. Imprimez ou exportez en PDF

## Sauvegarde

Le système crée automatiquement une sauvegarde à chaque ouverture :
- Emplacement : même dossier que le fichier
- Nom : `DSS_Backup_[date].xlsm`
- Conservation : 30 jours (nettoyage automatique)

## Problèmes Courants

| Problème | Solution |
|----------|----------|
| "Macros désactivées" | Fichier > Options > Activer les macros |
| "Projet VBA non accessible" | Fichier > Options > Faire confiance à l'accès VBA |
| KPIs affichent 0 | Cliquez sur "Accueil" pour rafraîchir |
| Barcode ne s'imprime pas | Vérifiez l'imprimante par défaut |
