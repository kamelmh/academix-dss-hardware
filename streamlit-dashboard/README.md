# Academix DSS - Streamlit Dashboard

Dashboard de démonstration pour Academix DSS - Système de gestion de stock pour quincailleries.

## Fonctionnalités

- 📊 **KPIs en temps réel** - Articles, valeur stock, alertes, rotation
- 📈 **Graphiques interactifs** - Pie charts, bar charts, gauges
- 🎯 **Classification ABC** - Visualisation de la classification
- ⚠️ **Alertes stock** - Produits en dessous du seuil
- 📋 **Transactions récentes** - Derniers mouvements

## Données de démonstration

Le dashboard utilise des données simulées:
- 40 articles (vis, boulons, outils, etc.)
- 4 catégories (Visserie, Fer, Électricité, Outillage)
- Valeur stock totale: ~50M DZD
- Alertes stock pour les produits critiques

## Lancement

```bash
# Installer les dépendances
pip install -r requirements.txt

# Lancer le dashboard
streamlit run app.py
```

## Déploiement sur Streamlit Cloud

1. Pousser ce dossier sur GitHub
2. Aller sur share.streamlit.io
3. Connecter le repo
4. Sélectionner `streamlit-dashboard/app.py`
5. Déployer
